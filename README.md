# 서울대 한국어 4A · 듣기 2

서울대 한국어 4A 3과 듣기 2(Track 29)의 빈칸 듣기 연습 웹앱입니다.

## 기능

- 문맥 속 핵심 어휘·표현 14개 빈칸 입력
- 정답 확인, 정답 보기, 다시 하기
- Track 29 음원 재생과 5초 앞·뒤 이동
- 0.5배속, 0.6배속, 0.75배속, 정상 속도 재생

## 실행

`index.html`을 브라우저로 열거나, 폴더에서 아래 명령을 실행한 뒤 `http://localhost:4173`으로 접속하세요.

```bash
python3 -m http.server 4173
```
